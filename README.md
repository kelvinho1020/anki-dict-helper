# anki-dict-helper

Chrome 擴充功能：在網頁上選取英文單字，看繁體中文解釋，一鍵加入 AnkiWeb。手機的 AnkiDroid 同步後就看得到。

不需要安裝電腦版 Anki。

## 安裝

1. 下載這個專案。
2. 打開 `chrome://extensions`，開啟右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾。

## 使用

1. 按工具列的圖示，再按「登入 AnkiWeb」。登入一次就會記住。
2. 回到圖示，選要加到哪個牌組和卡片類型（建議用「Basic」）。
3. 在任何網頁選取一個英文單字或片語，旁邊會出現「譯」按鈕。
4. 按「譯」看解釋。勾選想記的解釋，按「加入 Anki」。
5. 在 AnkiDroid 按同步。

卡片正面是單字；背面是音標、中文解釋、英文解釋、例句，以及你在網頁上看到的那一句。

## 資料來源

- 字典：劍橋英漢詞典（繁體）
- Anki：AnkiWeb 網頁版的內部 API。AnkiWeb 改版時可能需要更新。
